JSON ⇄ CSV Converter

Paste or upload JSON to get CSV, or CSV to get JSON. Quoting, embedded commas, newlines and nested objects are all handled, and nothing leaves your browser.

Everything runs locally in your browser and nothing is uploaded. CSV to JSON keeps all values as strings so data like "007" isn't corrupted. "Spreadsheet-safe cells" prefixes cells starting with = + - @ with an apostrophe so Excel or Sheets won't run them as formulas. Turn it on when the CSV is headed for a spreadsheet.
