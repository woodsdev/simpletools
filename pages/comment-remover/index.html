Code Comment Remover

Paste some code and every comment is stripped out. The language is detected automatically, and you can pick it yourself if the guess is wrong.

Everything runs locally in your browser and nothing is uploaded. Strings are left alone, so a hash or slashes inside quotes are safe, and Python docstrings stay put because they are strings, not comments. Auto-detect makes a best guess from the shape of the code; pick the language yourself if it guesses wrong.
